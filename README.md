# Exploratory-Data-Analysis-and-Interactive-Dashboarding-on-U.S.-Income-Tax-Returns

## 📌 Project Overview
This project focuses on analyzing **income tax return data** to uncover patterns in income distribution, deductions, taxable income, and tax liability across different income groups. The goal is to derive **data-driven insights** that can support policy analysis, economic studies, and financial decision-making.

The analysis follows an end-to-end data analytics workflow, including **data cleaning, exploratory data analysis (EDA), statistical insights, and interactive dashboarding**.

---

## 🎯 Objectives
- Clean and standardize raw income tax data for analysis  
- Identify income and tax contribution patterns across different taxpayer groups  
- Analyze skewness and concentration in taxable income and tax liability  
- Build an interactive **Power BI dashboard** for stakeholder-friendly insights

## 📁 File Descriptions

### 1️⃣ Data cleaning and EDA.ipynb
- Performed **data cleaning**:
  - Handled missing values and duplicates  
  - Standardized column names and data types  
  - Identified and treated outliers  
- Conducted **Exploratory Data Analysis (EDA)**:
  - Univariate analysis of income, deductions, and tax variables  
  - Distribution and skewness analysis  
  - Identification of high-contribution taxpayer segments  
- Used **Python libraries** such as:
  - `pandas`, `numpy`
  - `matplotlib`, `seaborn`

---

### 2️⃣ Dashboard.pbix
- Developed an **interactive Power BI dashboard** showcasing:
  - Total taxable income and tax liability KPIs  
  - Income-wise and tax-wise distribution analysis  
  - Concentration of tax contribution among high-income groups  
  - Trend and comparison visuals for key financial metrics  
- Designed for **clear storytelling and decision-making**

---

## 📊 Key Insights
- Income and tax liability distributions are **highly right-skewed**
- A small percentage of high-income taxpayers contribute a **disproportionately large share** of total tax revenue  
- Deductions vary significantly across income groups, impacting taxable income  
- Clear segmentation between low, middle, and high-income tax contributors
